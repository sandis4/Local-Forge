# Дистилляция DeepSeek Flash

Банк вопросов и раннер для получения ответов учителя через официальный API
DeepSeek. Ответы конвертируются в JSONL с `messages`, который понимает
`dataset_formatter.py` из Local Forge.

## Официальные параметры (проверено по документации)

| Параметр | Значение |
|---|---|
| Модель | `deepseek-flash` (сейчас DeepSeek-V4.1-Flash-1017) |
| Endpoint | `https://api.deepseek.com/chat/completions` (OpenAI-совместимый) |
| Авторизация | `Authorization: Bearer $DEEPSEEK_API_KEY` |
| Контекст | 1 000 000 токенов |
| Максимум вывода | 384K токенов (по умолчанию 8K без thinking, 64K с thinking) |
| Параллельные запросы | 2500 на аккаунт для Flash |
| Thinking | включён по умолчанию, `reasoning_effort`: `low` / `high` / `max`; отключается `{"thinking":{"type":"disabled"}}` |
| Logprobs | `logprobs: true` + `top_logprobs` от 0 до 20; вероятности есть и для ответа, и для `reasoning_content` |
| Температура | в thinking-режиме игнорируется; без thinking работает |

Цены за 1M токенов (Flash):

| | off-peak | peak |
|---|---|---|
| Вход, cache miss | $0.15 | $0.30 |
| Вход, cache hit | $0.003 | $0.006 |
| Выход | $0.60 | $1.20 |

Peak: 01:00–04:00 и 06:00–10:00 UTC по будням (по Москве — 04:00–07:00 и
09:00–13:00). В остальное время действует half-price off-peak.

Источники: [документация](https://api-docs.deepseek.com/),
[цены](https://api-docs.deepseek.com/quick_start/pricing),
[thinking](https://api-docs.deepseek.com/guides/thinking_mode/),
[лимиты](https://api-docs.deepseek.com/quick_start/rate_limit/).

## Файлы

| файл | назначение |
|---|---|
| `question_bank.py` | детерминированный генератор: 15 881 уникальный вопрос |
| `questions_3000.jsonl` | первые 3000 вопросов (сбалансировано по 12 доменам) |
| `make_questions.py` | материализация N вопросов в JSONL |
| `run_distill.py` | запросы к API, докачка, повторы, конвертация в обучение |
| `answers_3000.jsonl` | появится после запуска (ответы + reasoning + usage + уверенность) |
| `answers_3000.logprobs.jsonl.gz` | появится после запуска (шансы учителя по токенам) |
| `train_distill.jsonl` | появится после запуска (обычное SFT) |
| `train_distill.kd.jsonl.gz` | появится после запуска (SFT + `soft` для KD-обучения) |

## Запуск

```bat
set DEEPSEEK_API_KEY=sk-...
python run_distill.py --questions questions_3000.jsonl --dry-run
python run_distill.py --questions questions_3000.jsonl --concurrency 16
```

`--dry-run` показывает оценку токенов и цены без запросов. Повторный запуск
докачивает только недостающие вопросы: готовые строки в `answers_3000.jsonl`
пропускаются. Ошибки пишутся в `answers_3000.jsonl.errors.jsonl`; после
исправления причины просто запустите команду ещё раз.

Полезные ключи:

```bat
:: без рассуждений — дешевле примерно в 2.5 раза
python run_distill.py --thinking off

:: шансы только для ответа, top-5 (по умолчанию)
python run_distill.py --logprobs 5

:: шансы и для рассуждений, top-10
python run_distill.py --logprobs 10 --logprob-scope all

:: не сохранять шансы
python run_distill.py --logprobs 0

:: экономный thinking
python run_distill.py --thinking low

:: больше параллелизма (лимит аккаунта 2500)
python run_distill.py --concurrency 32

:: только пересобрать training JSONL из готовых ответов
python run_distill.py --convert-only
```

API-ключ читается только из переменной окружения, в файлы не записывается.
Код ошибки 402 означает, что на балансе нет средств; 429 и 5xx повторяются
автоматически с экспоненциальной задержкой.

### Контекст, reasoning и ответ

Reasoning DeepSeek часто длиннее всего контекста обучения: медиана ~2.4K
символов, а ответ — ~1.9K. При `max_length=512` почти любой ответ с
рассуждением был бы обрезан ещё до финальной части, и модель училась бы
на недописанном reasoning.

Поэтому:

- `--train-target auto` (по умолчанию) кладёт reasoning в данные только если
  он заведомо влезает вместе с ответом; иначе учим только финальный ответ;
- `--train-target answer` — всегда только ответ;
- `--train-target think` — всегда reasoning + ответ (нужен больший контекст);
- `--train-max-length 512` — тот же контекст, что в Local Forge; используется
  для решения «влезет ли reasoning» и для отчёта о длинных ответах;
- `--max-answer-tokens N` — попросить учителя отвечать короче (добавляется
  только в system-промпт API, в обучающие строки не попадает).

Рекомендуемые режимы:

```bat
:: 512 токенов: только ответы, без reasoning
python run_distill.py --thinking off --train-target answer --max-answer-tokens 400

:: 1024+ токенов: короткий reasoning + ответ
python run_distill.py --thinking low --train-target auto --train-max-length 1024

:: 2048+ токенов: полноценный reasoning
python run_distill.py --thinking high --train-target think --train-max-length 2048
```

System prompt в обучающих строках теперь совпадает с чатом Local Forge:
`You are Local Forge, a helpful AI assistant. Answer in the user language.`
Если модель училась с другим промптом, при инференсе контекст отличался бы.

Тренер в KD-режиме сам страхует данные: если ассистент не влез в контекст,
сначала выбрасывает reasoning и оставляет финальный ответ; если и ответ не
влез — пропускает сэмпл, а не учится на обрезке. В лог выводится предупреждение.

Если авто-план Local Forge из-за нехватки свободной RAM ставит контекст
128–512 токенов, большая часть ответов будет пропущена, и дистилляция почти
не даст эффекта. Варианты: закрыть тяжёлые приложения и поднять контекст,
взять для дистилляции модель поменьше (1–2 ГБ) или генерировать короткие
ответы (`--max-answer-tokens`, `--thinking off`).

## Оценка стоимости

Для 3000 вопросов (средний промпт ~100 символов):

| Режим | off-peak | peak |
|---|---|---|
| thinking high (≈2100 токенов на ответ) | ≈ $3.8 | ≈ $7.6 |
| без thinking (≈700 токенов) | ≈ $1.3 | ≈ $2.6 |

Для 15 000 вопросов умножьте примерно на 5: 19 / 38 $ с thinking high и
6.5 / 13 $ без него. Это грубая оценка: реальные токены выводятся после
запуска, а cache hit для общего system prompt снижает вход.

## Как вырастить банк до 15K

Генератор уже содержит 15 881 вопрос. Первые 3000 — это префикс полного
набора, поэтому рост не перетасовывает уже использованные вопросы:

```bat
python make_questions.py --count 6000  --out questions_6000.jsonl
python make_questions.py --count 15000 --out questions_15000.jsonl
```

Домены: программирование, математика, русский язык и литература, естественные
науки, техника и ИТ, быт и финансы, история и обществознание, деловая
переписка, менеджмент и продукт, логика, английский, креативное письмо.
Вопросы имеют `id`, `lang`, `domain`, `kind`, `difficulty`, `prompt`.

Если нужны новые темы, добавьте их в `DOMAINS` в `question_bank.py` — новые
вопросы появятся в конце банка и не изменят предыдущие 3000.

## Формат данных

Вопрос:

```json
{"id":"q_08fb138a62b2","lang":"ru","domain":"programming","kind":"project","difficulty":"medium","prompt":"..."}
```

Ответ учителя:

```json
{"id":"q_...","prompt":"...","reasoning":"...","answer":"...","usage":{...},"model":"deepseek-flash"}
```

Обучение (ассистент содержит рассуждение в `<think>...</think>`, как в
существующих данных Forge):

```json
{"messages":[
  {"role":"system","content":"You are Forge..."},
  {"role":"user","content":"..."},
  {"role":"assistant","content":"<think>...</think>\n\n..."}
],"source":"deepseek-flash"}
```

В Local Forge укажите `distill/train_distill.kd.jsonl.gz` как датасет,
включите «Дистилляция KD» и задайте вес KL (по умолчанию 0.5) и top-k (8).
Packing в KD-режиме отключается автоматически. Для обычного SFT без шансов
берите `train_distill.jsonl`.

## Шансы учителя (logprobs)

DeepSeek отдаёт не только выбранный токен, но и до 20 альтернатив с их
вероятностями. Это не полное распределение по словарю, но для дистилляции
полезно: видно, где учитель был уверен, а где колебался.

Runner по умолчанию запрашивает `logprobs: true` и `top_logprobs: 5`.
Хранится три вида данных:

- в `answers_3000.jsonl` — сводка `teacher`: средний logprob, perplexity,
  число токенов и токенов вне top-k для ответа и для рассуждений;
- в `answers_3000.logprobs.jsonl.gz` — компактные распределения по токенам:
  `{"id":"q_...","answer":[{"t":"токен","lp":-0.12,"top":[["токен",-0.12],...]}]}`;
- в `train_distill.kd.jsonl.gz` — готовые обучающие строки с полем `soft`.

Ограничения:

- доступны только top-k альтернативы, а не весь словарь;
- вероятности есть только для сгенерированных токенов (ответ и рассуждение),
  но не для токенов промпта;
- если выбранный токен не попал в top-20, его `logprob` равен `-9999.0`;
- `--logprob-scope all` добавляет распределения для `reasoning_content`;
- логи вероятностей не влияют на цену токенов, но увеличивают трафик и размер
  файла: top-5 по ответу — десятки-сотни МБ на 3K вопросов, top-20 + all —
  в несколько раз больше.

Как применять:

1. **Фильтрация и сортировка** ответов по perplexity: сомнительные ответы можно
   вручную проверить или исключить из обучения.
2. **KD-обучение в Local Forge**: датасет `train_distill.kd.jsonl.gz`,
   галочка «Дистилляция KD». Тренер проецирует top-k учителя на первый токен
   ученика, нормирует распределение и добавляет KL к обычному CE. Работает
   поверх LoRA/LISA/AMP; в логе видно `KD: ...`.
3. **Точность проекции**: токенизаторы DeepSeek и ученика разные, поэтому
   границы токенов совпадают не везде (на тесте с Gemma — около 80% стартов).
   KD-сигнал есть на совпавших позициях, остальные учит обычный CE.

## Важно

- Проверяйте выборку ответов: учитель может ошибаться, особенно в редких
  фактах. Для математики и кода полезно прогнать автопроверку.
- Не отправляйте в API персональные данные и секреты: вопросы банка
  синтетические, но при добавлении своих промптов это ваша ответственность.
- Thinking-режим дороже и медленнее, но даёт рассуждения для обучения. Если
  нужен только стиль ответов, запускайте с `--thinking off`.
